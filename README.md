
CInBora is a college carpooling project we are developing as coursework of the Integration and Evolution of Information Systems class. This repository contains the code for its front-end client.

## How to run this project

First of all, you need to install Node.JS at  https://nodejs.org/pt, click get Node.js.

<img width="1608" height="680" alt="image" src="https://github.com/user-attachments/assets/ffa57c28-eeb8-45b9-b2bf-e51c39d896f9" /># CInBora (Front-end Client)

After, you must install all dependencies. Enter the following in your terminal:

```
npm i
```

When all the dependencies are installed, run:

```
npm run dev
```

<img width="281" height="125" alt="image" src="https://github.com/user-attachments/assets/e1513903-defd-4adb-a77d-9ead96492ad7" />

The client will be hosted at port:5173, hold CTRL and click on `http://localhost:5173/`
